# Gemini AI Chatbot

A Streamlit chat app using Google Gemini (gemini-2.5-flash) with conversation history kept in the session. Built for education.

## Setup

```bash
pip install -r requirements.txt
```n
Create a `.env` file with your key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```n
## Run

```bash
streamlit run app.py
```n
## Tech stack

Python, Streamlit, Google Generative AI
